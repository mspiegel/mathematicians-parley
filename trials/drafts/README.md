# Trial drafts

Unfinished proofs and short probes the trials' writers left beside their
proofs, as `.txt` so that no tool reads them, each under the git worktree
it was written in. Their imports are as the writers left them, with the
paths of before the collections (`proofs/<file>/<theorem>`). None was
finished; a probe of a few lines is a statement the writer tried to read.
They are kept as the start of tests, not as proofs that pass.
